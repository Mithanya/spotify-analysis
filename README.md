# Spotify Songs Data Analysis using Python and MySQL

A Python and MySQL based project used to manage and analyze Spotify songs data from a CSV dataset.

## Features

- Import CSV data into MySQL
- Add, update, delete, and search songs
- Perform SQL-based song analysis
- Display formatted results in terminal

## Technologies Used

- Python
- MySQL
- CSV
- MySQL Connector

## Analysis Performed

- Top popular songs
- Most frequent artists
- Average popularity score
- Highest energy songs
- Artist-wise song analysis

## Run the Project

1. Create database:

CREATE DATABASE spotify_db;

2. Install package:

pip install mysql-connector-python

3. Run the project:

python analysis.py
